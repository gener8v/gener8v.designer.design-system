Why this system

Accessible by default

Every text pair is measured for contrast in light and dark, and the components run under axe — both gate CI, so a regression fails the build rather than reaching a user.

One token source

Colour, type, space and motion are defined once and emitted as CSS variables, TypeScript, a Tailwind preset and DTCG for design tools.

Built for AI-assisted delivery

A Claude Code plugin teaches the rules and the class names, and a which-component-for-which-job guide says what to reach for — and what not to.

Get started

  1. Install

    Public on npm under MIT. No token, no account.

    npm i @gener8v/ui @gener8v/tokens @gener8v/icons

  2. Import

    One stylesheet first, then the components.

    import '@gener8v/ui/styles.css';
import { Button, Table, Dialog } from '@gener8v/ui';

  3. Add the Claude Code plugin

    It teaches Claude the rules, the class names, the templates and which component fits which job.

    /plugin marketplace add gener8v/gener8v.designer.design-system
