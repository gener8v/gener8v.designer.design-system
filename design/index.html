Foundations

foundations/color.html

Color

Six roles, two working ramps, and status held to five steps — generated in OKLCH

foundations/icons.html

Icons

Phosphor, inline SVG on currentColor, sized in em so they track the type

foundations/image.html

Imagery

Figures sit on the ground with a hairline and a radius; atmosphere comes from dot grid and grain

foundations/layout.html

Spacing & elevation

A 4px spacing scale, 6px radius, and three soft elevation steps tuned for a light ground

foundations/type.html

Typography

Inter at 500 for headings over Inter for body, with IBM Plex Mono as the technical voice

Components

components/buttons.html

Buttons

Six variants, five sizes, icon and loading states — solid primary on a near-white ground

components/cards.html

Cards & tags

Hairline surfaces with a mono kicker; tags carry status, never decoration

components/charts.html

Charts

Bar, stacked, line and sparkline — palette validated for colour-blind separation, table view always available

components/command.html

Command, tree & code

Command palette, hierarchy tree and code block — all keyboard-first

components/data.html

Data display

Stats, meters, description lists and avatars — tabular figures throughout

components/disclosure.html

Menu & disclosure

Dropdown menu, accordion and segmented control — open state carried by aria-expanded

components/feedback.html

Feedback

Dialog, alerts, toast, tooltip and callout — one tone vocabulary shared with states

components/flow.html

Flow controls

Stepper, progress, timeline, pagination and skeletons — the parts a flow is built from

components/forms.html

Forms

Native controls on the shared control-height scale, so fields and buttons line up

components/graph.html

Knowledge graph

Canvas-rendered, Barnes-Hut layout — 1,000 nodes at 0.8ms per tick; radius is sqrt(degree)

components/inputs.html

Advanced inputs

Combobox, slider, file drop and calendar — native controls wherever one exists

components/integrations.html

Integrations & keys

Connections, masked credentials, API key scopes and event rules

components/library.html

Document library

Browsing MD, PDF, XLSX and CSV — list, grid and preview panes

components/navigation.html

Navigation

Header, sidebar, tabs, breadcrumbs and the hamburger — active state keys off aria-current

components/states.html

States

The six states every flow passes through — most systems ship only the first

components/table.html

Table

Hairline rules, mono headers, tabular figures — sort state carried by aria-sort
