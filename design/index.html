Built to be relied on.

Every rule is checked rather than assumed — so a product built on it inherits the checks, not just the look.

Accessible by default

Every text pair is measured for contrast in light and dark, and the components run under axe — both gate CI, so a regression fails the build rather than reaching a user.

One token source

Colour, type, space and motion are defined once and emitted as CSS variables, TypeScript, a Tailwind preset and DTCG for design tools.

Built for AI-assisted delivery

A Claude Code plugin teaches the rules and the class names, and a which-component-for-which-job guide says what to reach for — and what not to.

Three steps to the first screen.

Install, import one stylesheet, and teach Claude Code the rules. Then start from a template rather than a blank file.

  1. Install

    Public on npm under MIT. No token, no account.

    npm i @gener8v/ui @gener8v/tokens @gener8v/icons

  2. Import

    One stylesheet first, then the components.

    import '@gener8v/ui/styles.css';
import { Button, Table, Dialog } from '@gener8v/ui';

  3. Add the Claude Code plugin

    It teaches Claude the rules, the class names, the templates and which component fits which job.

    /plugin marketplace add gener8v/gener8v.designer.design-system

Guidance which component for which job

Screens Which component for a whole page, a shell, or the structure a page sits in Overlays Which component for something that floats above the page — a modal, a side panel, a hint, a preview Status and feedback Which component for telling someone what happened, what state a thing is in, or that it is loading Navigation Which component for moving between places, switching views, or narrowing what a list shows Data Which component for figures, tables, charts, lists of records, or history Input Which component for an action someone presses or a value someone enters or picks Reading Which component for a document, prose, code, sources or type someone reads Agents and live work Which component for a conversation with an agent, or work that is running right now
