# Product Language Rules

Rules for text that appears inside the product: headings, buttons, actions, column headers, and status text.

Examples are given in two domains to show that the rules are about form, not subject matter.

---

## Rule 1 — Match grammatical form to surface type

| Surface | Required form | Finance antipattern | Education antipattern | Finance example | Education example |
|---|---|---|---|---|---|
| Buttons, menu actions | Imperative, base form | Confirming Trial Balance | Assigning Lesson | Confirm Trial Balance | Assign Lesson |
| Checklist and task items | Imperative, base form | Account reconciliation | Submission review | Reconcile accounts | Review submissions |
| Page and section titles | Noun phrase | Confirming the trial balance | Viewing the roster | Trial balance | Course roster |
| Table column headers | Noun phrase | The File It Came As | The Date It Is Due | Source File | Due Date |
| In-progress status | Gerund | Reconcile in progress | Grade in progress | Reconciling… | Grading… |
| Completed status | Past participle | Sends report | Returns assignment | Report sent | Assignment returned |

Capitalization in this table follows Rule 11.

## Rule 2 — No gerunds on actionable surfaces

If the user is meant to do something, the label starts with a verb in base form. Gerunds are reserved for transient states.

- Finance: **Confirm Trial Balance**, not "Confirming Trial Balance"
- Education: **Publish Grades**, not "Publishing Grades"

## Rule 3 — No nominalized verbs

Nominalizations suppress the actor.

- Finance: **Delete Records**, not "Deletion of Records" or "Deleting Records"
- Education: **Enroll Students**, not "Enrollment of Students"

## Rule 4 — No relative clauses in labels

Covers explicit and zero relatives alike. If a label needs a clause to be understood, rewrite the label.

- Finance: "The File That It Came As" → **Source Format**
- Education: "The Student You Selected" → **Selected Student**; "Lessons the Class Has Completed" → **Completed Lessons**

## Rule 5 — Never strand a preposition at the end of a label

- Finance: "The Period This Applies To" → **Applicable Period**
- Education: "The Unit This Belongs To" → **Parent Unit**

## Rule 6 — One voice per screen

Choose whether labels address the user or describe the system, and hold it across every element on the surface.

- Finance: do not mix "Send Report" with "Sends Report"
- Education: do not mix "Assign Lesson" with "Assigns Lesson to Class"

## Rule 7 — Front-load the distinguishing word

The first word carries the scan. Reorder so the difference lands early, or rename.

- Finance: "Export Ledger" and "Export Journal" scan poorly as a pair
- Education: "View Student Progress" and "View Class Progress" scan poorly as a pair — use **Student Progress** and **Class Progress**

## Rule 8 — No articles in labels

Applies to headings, buttons, and columns alike.

- Finance: "Confirm the Trial Balance" → **Confirm Trial Balance**
- Education: "Open the Gradebook" → **Open Gradebook**

## Rule 9 — Verb + object, nothing more

Actionable labels take two to three words. Conditions, qualifiers, and scope belong in helper text.

- Finance: **Post Entries**, not "Post Entries for the Current Period"
- Education: **Send Reminder**, not "Send Reminder to Students With Missing Work"

## Rule 10 — When a rule and clarity conflict, clarity wins — and log the exception

A rule that gets silently broken often is a rule that needs revising.

## Rule 11 — Title Case on buttons and column headers; sentence case everywhere else

| Surface | Capitalization | Example |
|---|---|---|
| Buttons, menu actions | Title Case | Confirm Trial Balance |
| Table column headers | Title Case | Source File |
| Page and section titles | Sentence case | Trial balance |
| Checklist and task items | Sentence case | Reconcile accounts |
| Status text | Sentence case | Report sent |
| Helper and body text | Sentence case | Entries post to the current period. |

Within Title Case, capitalize every word except articles, coordinating conjunctions, and prepositions of four letters or fewer — unless the word is first or last.

---

## Review checklist

For each new or changed label:

- [ ] Surface type identified, form matches Rule 1
- [ ] Capitalization matches Rule 11
- [ ] No gerund unless it is an in-progress state
- [ ] No relative clause, no stranded preposition
- [ ] No leading article
- [ ] Voice matches the rest of the screen
- [ ] Three words or fewer for actions
